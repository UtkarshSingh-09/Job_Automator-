# 🚀 Resume Agent

> **Autonomous Internship-Matching, Resume Generation & Auto-Apply System**  
> Custom-tailored for Utkarsh Singh (B.Tech CS @ SRM University Amaravati)

---

## ⚡ Quick Start

### 1. Install dependencies
```bash
uv sync
```

### 2. Configure Environment
```bash
cp .env.example .env
# Fill in your API keys in .env
```

### 3. Initialize Database
```bash
uv run resume-agent init
```

### 4. Check Status
```bash
uv run resume-agent status
```
